## Video Conference Web App

A real-time video conferencing web application built using **WebRTC**, **Socket.io**, **Node.js**, and **Express.js**.  
It allows users to create or join meeting rooms and communicate through video, audio, text chat, and screen sharing.

### 🚀 Features
- Real-time video & audio calling
- Create/join meeting rooms with unique room IDs
- Screen sharing support
- Toggle mic & camera controls
- In-call chat messaging
- Multi-user support
- Responsive UI (mobile + desktop)
- Peer-to-peer encrypted communication using WebRTC

### 🛠 Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Real-time:** WebRTC, Socket.io  
- **Styling:** CSS / Tailwind  
- **Deployment:** Render / Vercel / Netlify
